## 1. 项目概述

**Markdown+** 是一款桌面端 Markdown 编辑器，采用 Electron + Vue 3 + TypeScript 技术栈。

- **核心特色**: 自定义 `.mdx` 文件格式（ZIP 打包 Markdown + 资源）
- **当前阶段**: 阶段1-4 已完成，阶段5 部分完成，即时渲染(IR)模式已实现
- **开发模式**: `npm run dev`
- **类型检查**: `npm run typecheck`
- **代码检查**: `npm run lint`

## 3. 核心模块说明

### 3.1 布局系统（src/components/layout/）

#### AppHeader.vue
- **功能**: 自定义无边框窗口标题栏（`-webkit-app-region: drag`）
- **包含**: Logo、文件菜单（新建/打开/打开文件夹/最近文件/保存/另存为/导入/导出）、快捷操作按钮、主题切换按钮、窗口控制按钮（最小化/最大化/关闭）
- **窗口控制**: 通过 IPC 调用主进程 `window:minimize`/`window:maximize`/`window:close`，监听最大化状态变化
- **快捷键**: Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存、Ctrl+Shift+S 另存为
- **事件**: `@toggle-sidebar` - 切换侧边栏折叠状态
- **最近文件**: 子菜单展示最近打开的文件列表，支持清除

#### ToolBar.vue
- **功能**: 编辑工具栏
- **包含**: 格式按钮组（粗体、斜体、删除线）、块级元素（标题下拉、列表、引用、代码块）、插入元素（链接、图片、表格）
- **对话框**: 内置链接/图片/代码块插入对话框（弹出 modal）
- **事件机制**: 通过 `window.dispatchEvent` 发送 `editor:format`/`editor:heading`/`editor:link`/`editor:image`/`editor:codeBlock` 自定义事件

#### SideBar.vue
- **功能**: 侧边栏（可折叠）
- **Props**: `collapsed?: boolean`
- **事件**: `@toggle` - 切换折叠状态
- **展开状态**: 直接内嵌 FileExplorer 组件（不再使用 Tab 切换面板）
- **折叠状态**: 显示图标栏（新建文件、打开文件、打开文件夹、展开按钮）

#### StatusBar.vue
- **功能**: 底部状态栏
- **包含**:
  - 左侧：文件名、字数统计、文件大小、光标位置（行/列）
  - 右侧：模式切换按钮（分屏预览 ↔ 源码编辑 ↔ 即时渲染）、保存状态、版本号
- **模式切换**: 在 `split`（分屏预览）、`source`（源码编辑）和 `ir`（即时渲染）之间循环

### 3.2 侧边栏（src/components/sidebar/）

#### FileExplorer.vue
- **功能**: 文件夹浏览器 + 文件操作
- **文件夹浏览**: 打开文件夹后显示文件夹内容（文件和子文件夹），支持导航（进入子文件夹、返回上一级、关闭文件夹）
- **右键菜单**:
  - 空白区域：新建文件、新建文件夹、刷新
  - 文件：打开、重命名、删除、复制路径
  - 文件夹：新建文件、新建文件夹、刷新、重命名、删除、复制路径
- **输入对话框**: 新建/重命名操作使用自定义输入弹窗（非 `prompt()`）
- **文件高亮**: 当前打开的文件高亮显示，未保存时显示修改指示器
- **空状态**: 未打开文件夹时显示空状态提示
- **事件**: `@collapse` - 折叠侧边栏

### 3.3 编辑器（src/components/editor/）

#### TabBar.vue
- **功能**: 多文件标签栏
- **特性**: 显示所有打开的文件标签，当前激活标签高亮，未保存文件显示圆点指示器
- **交互**:
  - 点击标签切换文件
  - 点击关闭按钮或鼠标中键关闭标签
  - 关闭未保存标签时弹出保存确认对话框
  - 标签栏可水平滚动

#### EditorPanel.vue
- **功能**: 编辑器容器
- **结构**: TabBar + 编辑器区域
- **编辑器区域**:
  - `source` 模式：仅显示 SourceEditor
  - `split` 模式：使用 Splitpanes 组件实现可拖拽的左右分栏（SourceEditor + PreviewPanel）
  - `ir` 模式：显示 IrEditor（即时渲染，内联标记随光标展开/折叠）

#### SourceEditor.vue
- **功能**: Markdown 源码编辑器
- **技术**: CodeMirror 6
- **特性**:
  - Markdown 语法高亮（@codemirror/lang-markdown）
  - 代码块多语言高亮（支持 30+ 语言）
  - 行号、当前行高亮、选择匹配高亮
  - 自动补全（标题、列表、代码块、链接等）
  - 快捷键（Ctrl+B/I/K/H、Tab 缩进、Ctrl+/注释）
  - 查找替换（Ctrl+F/H）
  - 浅色/深色主题自适应（Compartment 动态切换）
  - 拖拽/粘贴图片插入
  - 与 fileStore 双向内容同步（防循环标志 `isSyncing`）
- **暴露方法**: `toggleSearchPanel()`, `focus()`, `getView()`

#### PreviewPanel.vue
- **功能**: Markdown 预览
- **技术**: markdown-it + Shiki
- **特性**:
  - GitHub 风格 Markdown 渲染
  - 代码块语法高亮（Shiki，github-light/github-dark 主题，30+ 语言）
  - 任务列表渲染
  - 表格渲染
  - 图片加载：将 .mdx 内相对路径转换为 data URL（带缓存）
  - 防抖渲染优化（100ms）
  - 浅色/深色主题自适应
  - 滚动同步支持
- **暴露方法**: `scrollTo()`, `scrollToLine()`

#### IrEditor.vue（即时渲染模式，已启用）
- **功能**: 即时渲染编辑器（类似 Typora/Vditor IR 模式）
- **技术**: ProseMirror + CSS `::before`/`::after` 伪元素
- **特性**:
  - 块级标记：标题 `#`、引用 `>`、代码块 ` ``` `、分割线 `---`、列表 `-` / `1.` 始终可见
  - 内联标记：粗体 `**`、斜体 `*`、删除线 `~~`、代码 `` ` ``、链接 `[]()` 默认隐藏
  - 选区追踪：光标移到带标记文本附近时，内联标记自动淡入显示（`ir-plugin.ts`）
  - 任务列表：显示 `- [ ]` / `- [x]` 标记语法
  - 图片拖放/粘贴插入
  - 与 fileStore 双向内容同步（防循环标志 `isUpdating`）
- **Schema 扩展**: `data-mark`（内联标记）、`data-lang`（代码块语言）、`data-checked`（任务列表状态）
- **暴露方法**: `setBlockTypeCommand()`, `toggleHeadingLevel()`, `insertImage()`, `focus()`
- **状态**: 活跃，为默认编辑模式

#### WysiwygEditor.vue（已废弃）
- **功能**: 所见即所得编辑器历史实现
- **技术**: ProseMirror
- **特性**: Schema 定义、Markdown 双向转换、块级/行内节点、浮动工具栏、任务列表、图片拖放
- **状态**: 已废弃，当前 UI 不提供 WYSIWYG 模式入口，后续不再启用

#### FloatToolbar.vue（已废弃）
- **功能**: 浮动格式工具栏（选中文字时出现）
- **Props**: top, left, isBold, isItalic, isStrikethrough, isCode, isLink

### 3.5 类型定义（src/types/）

#### mdx.ts
前端镜像的 MDX 格式类型定义，与 `electron/mdx/schema.ts` 保持一致。包含 `MdxDocument`、`MdxImageAsset`、`MdxAttachmentAsset` 等接口及工厂函数。

#### electron.d.ts
扩展全局 `Window` 接口，添加 `electronAPI` 属性类型声明。

#### splitpanes.d.ts
`splitpanes` 组件的类型声明。

### 3.6 Composables（src/composables/）

#### useMdx.ts
单文档 MDX 操作 composable。管理单个文档的新建/打开/保存/导入/导出。**注意**: 此 composable 管理单文档状态，file store 中的多标签逻辑直接调用 `window.electronAPI`。

### 5.3 主进程处理器

- **file-handlers.ts**: 文件对话框、最近文件管理（持久化到 `recent-files.json`）、文件夹读取（过滤 `.mdx`/`.md` 文件）、文件/文件夹 CRUD
- **mdx-handlers.ts**: MDX 文件完整生命周期管理（新建→打开→编辑→保存→关闭），图片/附件资源管理，临时目录管理

## 8. 开发约定

### 8.1 文件命名

- 组件: PascalCase (如 `AppHeader.vue`)
- 工具函数: camelCase (如 `useMdx.ts`)
- 常量: UPPER_SNAKE_CASE (如 `IPC_CHANNELS`)

### 8.2 Vue 组件规范

```vue
<script setup lang="ts">
// 1. 导入
import { ref, computed } from 'vue'

// 2. 类型定义
interface Props {
  collapsed?: boolean
}

// 3. Props/Emits
const props = withDefaults(defineProps<Props>(), {
  collapsed: false
})
const emit = defineEmits<{
  toggle: []
}>()

// 4. 状态
const activePanel = ref<PanelType>('files')

// 5. 方法
function toggleSidebar(): void {
  emit('toggle')
}
</script>
```

### 8.3 样式规范

- 使用 Tailwind CSS utility classes
- 组件级样式使用 `<style scoped>`
- 主题颜色使用 CSS 变量
- 尺寸变量：`--header-height`, `--sidebar-width` 等

### 8.4 IPC 通信规范

- 所有 IPC 调用必须通过 `window.electronAPI`
- IPC 通道常量集中定义在 `electron/ipc/channels.ts`
- 主进程 handlers 注册在 `electron/ipc/` 目录
- 类型定义在 `electron/preload.ts`

### 8.5 状态管理规范

- `fileStore` 管理多标签页和文件夹浏览状态
- 向后兼容的 computed 代理（`currentFile`, `document`, `fileContent`）从 `activeTab` 读取
- 写入操作代理到 `activeTab`，通过 `tabs.value` 数组直接修改

## 9. 常见问题排查

| 问题 | 可能原因 | 解决 |
|-----|---------|------|
| `npm run dev` 报错找不到 index.js | 输出路径配置错误 | 检查 electron.vite.config.ts 的 outDir |
| 主题不生效 | CSS 变量未定义 | 检查 styles/index.css 中的变量定义 |
| IPC 调用无响应 | preload 未正确暴露 | 检查 electron/preload.ts |
| 类型检查失败 | 缺少类型声明 | 添加 .d.ts 文件或类型断言 |
| 多标签页状态不同步 | 主进程仅支持单文档 | 渲染进程通过 tabs 数组管理，切换标签时需要重新调用 IPC |
| 窗口控制按钮不工作 | 无边框窗口配置 | 检查 main.ts 的 frameless 配置和 `-webkit-app-region` |

## 10. 扩展指南

### 添加新的 IPC 通道

2. **preload.ts**: 添加 `ipcRenderer.invoke` 调用和类型

1. 创建新组件（如 `SearchPanel.vue`）
2. 在 `SideBar.vue` 中添加条件渲染

### 添加新的编辑模式

1. **stores/file.ts**: 更新 `EditorMode` 类型
2. **EditorPanel.vue**: 添加新的模式渲染逻辑
3. **StatusBar.vue**: 更新模式切换按钮

### IR 模式开发参考

IR（即时渲染）模式的核心设计原则：

1. **CSS 伪元素方案**: 使用 `::before`/`::after` 显示 Markdown 标记语法，而非修改 ProseMirror 文档模型
2. **选区追踪**: `ir-plugin.ts` 检测光标附近是否含有标记文本，切换 `ir-show-markers` class
3. **展开/折叠**: 内联标记默认 `opacity: 0`（隐藏），选区靠近时切换为 `opacity: 0.4`（淡入显示）
4. **块级标记始终可见**: 标题 `#`、引用 `>`、代码块 ` ``` `、分割线 `---`、列表标记不受选区影响
5. **Schema 扩展**: 不创建独立 schema，仅添加 `data-mark`/`data-lang`/`data-checked` 属性到现有 `markdownSchema`

### 启用 WYSIWYG 模式

1. **stores/file.ts**: 将 `EditorMode` 扩展为 `'wysiwyg' | 'split' | 'source' | 'ir'`
2. **EditorPanel.vue**: 添加 WYSIWYG 模式的渲染逻辑
3. **StatusBar.vue**: 添加 WYSIWYG 模式到循环切换
