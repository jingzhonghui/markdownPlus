## 1. 项目概述

**Markdown+** 是一款桌面端 Markdown 编辑器，采用 Electron + Vue 3 + TypeScript 技术栈。

- **核心特色**: 自定义 `.mdx` 文件格式（ZIP 打包 Markdown + 资源）
- **当前阶段**: 阶段1-2 完成，阶段3A 完成（源码编辑器）
- **开发模式**: `npm run dev`
- **类型检查**: `npm run typecheck`
- **代码检查**: `npm run lint`

## 3. 核心模块说明

### 3.1 布局系统（src/components/layout/）

#### AppHeader.vue
- **功能**: 顶部菜单栏
- **包含**: Logo、菜单按钮、主题切换按钮、导出按钮
- **事件**: `@toggle-sidebar` - 切换侧边栏折叠状态

#### ToolBar.vue
- **功能**: 编辑工具栏
- **包含**: 格式按钮组（粗体、斜体、标题、列表等）
- **状态**: 当前编辑模式（来自 file store）

#### SideBar.vue
- **功能**: 侧边栏（可折叠）
- **Props**: `collapsed?: boolean`
- **事件**: `@toggle` - 切换折叠状态
- **面板**: 文件浏览器 / 资源管理器（Tab 切换）
- **折叠按钮**: 展开状态显示 `<<`，折叠状态显示 `>>`

#### StatusBar.vue
- **功能**: 底部状态栏
- **包含**: 
  - 左侧：模式切换按钮（循环切换：所见即所得 → 分屏 → 源码）
  - 中间：字数统计、文件大小
  - 右侧：光标位置、保存状态

### 3.2 侧边栏面板（src/components/sidebar/）

#### FileExplorer.vue
- **功能**: 文件列表
- **状态**: 选中文件高亮
- **交互**: 新建文件按钮

#### AssetManager.vue
- **功能**: 资源管理（图片）
- **显示**: 图片缩略图网格
- **交互**: 添加资源按钮

### 3.3 编辑器（src/components/editor/）

#### EditorPanel.vue
- **功能**: 编辑器容器
- **根据模式显示不同编辑器**:
  - `wysiwyg`: WysiwygEditor
  - `split`: WysiwygEditor + PreviewPanel
  - `source`: SourceEditor

#### WysiwygEditor.vue
- **功能**: 所见即所得编辑器
- **技术**: ProseMirror（待实现）
- **占位**: 当前为占位组件

#### SourceEditor.vue
- **功能**: Markdown 源码编辑器
- **技术**: CodeMirror 6
- **特性**:
  - Markdown 语法高亮（@codemirror/lang-markdown）
  - 代码块多语言高亮（支持 30+ 语言）
  - 行号、当前行高亮、选择匹配高亮
  - 自动补全（标题、列表、代码块、链接等）
  - 快捷键（Ctrl+B/I/K/H、Tab 缩进、Ctrl+/注释）
  - 查找替换（Ctrl+F/H）
  - 浅色/深色主题自适应

#### PreviewPanel.vue
- **功能**: Markdown 预览
- **技术**: markdown-it + Shiki
- **特性**:
  - GitHub 风格 Markdown 渲染
  - 代码块语法高亮（Shiki，支持 30+ 语言）
  - 任务列表渲染
  - 表格渲染
  - 防抖渲染优化（100ms）
  - 浅色/深色主题自适应

### 3.4 状态管理（src/stores/）

#### theme.ts
```typescript
interface ThemeState {
  theme: 'light' | 'dark' | 'system'
  followSystem: boolean
  systemPreference: 'light' | 'dark'
  currentTheme: 'light' | 'dark'  // 计算属性
  isDark: boolean                 // 计算属性
}

// 方法
- initTheme()          // 初始化主题（读取 localStorage，监听系统主题变化）
- setTheme(theme)      // 设置主题
- toggleTheme()        // 切换浅色/深色主题
- getSystemTheme()     // 获取系统主题偏好
```

#### file.ts
```typescript
interface FileState {
  currentFile: FileInfo | null

// 方法
- init()               // 初始化
- setEditMode(mode)    // 设置编辑模式
```

## 8. 开发约定

### 8.1 文件命名

- 组件: PascalCase (如 `AppHeader.vue`)
- 工具函数: camelCase (如 `useEditor.ts`)
- 常量: UPPER_SNAKE_CASE (如 `IPC_CHANNELS.ts`)

### 8.2 Vue 组件规范

```vue
<script setup lang="ts">
// 1. 导入
import { ref, computed } from 'vue'

// 2. 类型定义
interface Props {
  collapsed?: boolean
}

// 3. Props/Emits
const props = withDefaults(defineProps<Props>(), {
  collapsed: false
})
const emit = defineEmits<{
  toggle: []
}>()

// 4. 状态
const activePanel = ref<PanelType>('files')

// 5. 方法
function toggleSidebar(): void {
  emit('toggle')
}
</script>
```

### 8.3 样式规范

- 使用 Tailwind CSS utility classes
- 组件级样式使用 `<style scoped>`
- 主题颜色使用 CSS 变量
- 尺寸变量：`--header-height`, `--sidebar-width` 等

### 8.4 IPC 通信规范

- 所有 IPC 调用必须通过 `window.electronAPI`
- 主进程 handlers 集中注册在 `electron/ipc/` 目录
- 类型定义在 `electron/preload.ts`

## 9. 常见问题排查

| 问题 | 可能原因 | 解决 |
|-----|---------|------|
| `npm run dev` 报错找不到 index.js | 输出路径配置错误 | 检查 electron.vite.config.ts 的 outDir |
| 主题不生效 | CSS 变量未定义 | 检查 styles/index.css 中的变量定义 |
| IPC 调用无响应 | preload 未正确暴露 | 检查 electron/preload.ts |
| 类型检查失败 | 缺少类型声明 | 添加 .d.ts 文件或类型断言 |
