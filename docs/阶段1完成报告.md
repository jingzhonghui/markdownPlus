## 项目结构

```
markdown-plus/
├── electron/                    # Electron 主进程
│   ├── main.ts                  # 主进程入口
│   ├── preload.ts               # 预加载脚本（IPC 类型定义）
│   └── ...
├── src/                         # Vue 渲染进程
│   ├── App.vue                  # 根组件
│   ├── main.ts                  # 渲染进程入口
│   ├── components/
│   │   ├── layout/              # 布局组件
│   │   │   ├── AppHeader.vue    # 顶部菜单栏
│   │   │   ├── ToolBar.vue      # 工具栏
│   │   │   ├── SideBar.vue      # 侧边栏容器
│   │   │   └── StatusBar.vue    # 状态栏
│   │   ├── sidebar/             # 侧边栏面板
│   │   │   ├── FileExplorer.vue # 文件浏览器
│   │   │   └── AssetManager.vue # 资源管理器
│   │   └── editor/              # 编辑器组件
│   │       ├── EditorPanel.vue  # 编辑器面板容器
│   │       ├── WysiwygEditor.vue # 所见即所得编辑器
│   │       ├── SourceEditor.vue  # 源码编辑器
│   │       └── PreviewPanel.vue  # 预览面板
│   ├── stores/                  # Pinia 状态管理
│   │   ├── theme.ts             # 主题状态
│   │   └── file.ts              # 文件状态
│   └── styles/
│       └── index.css            # 全局样式 + CSS 变量
├── docs/                        # 项目文档
├── package.json                 # 项目依赖和脚本
├── electron.vite.config.ts      # electron-vite 配置
├── tailwind.config.js           # Tailwind CSS 配置
├── eslint.config.mjs            # ESLint 配置
├── tsconfig.json                # TypeScript 配置
└── electron-builder.yml         # 打包配置
```

## 可用命令

```bash
# 开发模式
npm run dev

# 类型检查
npm run typecheck

# 代码检查
npm run lint

# 代码格式化
npm run format

# 构建
npm run build

# 打包
npm run build:win
npm run build:mac
npm run build:linux
```
